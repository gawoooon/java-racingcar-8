# 미션 - 자동차 경주 게임


## ⚙️ 구현할 기능 목록

### 1. 도메인 (Model)
* **`Car` (자동차) 객체**
    * `Car`는 이름(String)과 위치(int)를 속성으로 가진다.
    * 이름이 **5자 이하**인지 검증한다. (`IllegalArgumentException` 발생)
    * 이름이 **비어있거나 공백만으로 구성**되어 있는지 검증한다. (`IllegalArgumentException` 발생)
* **`Cars` (자동차 일급 컬렉션) 객체**
    * `List<Car>`를 관리한다.
    * **전진/정지** 로직을 수행한다.
        * 0~9 사이의 무작위 값을 생성한다.
        * 무작위 값이 **4 이상이면 전진** (위치 + 1), 4 미만이면 정지한다.
    * 시도할 횟수만큼 모든 자동차의 전진/정지를 반복 실행한다.
    * 가장 멀리 이동한 자동차를 찾아 우승자 리스트(`List<String>`)를 반환한다. (공동 우승 가능)

---

### 2. 입력 (View / Controller)
* "경주할 자동차 이름을 입력하세요..." 프롬프트를 출력하고 사용자 입력을 받는다.
* "시도할 횟수는 몇 회인가요?" 프롬프트를 출력하고 사용자 입력을 받는다.
* 입력받은 시도 횟수가 **유효한 양의 정수**인지 검증한다.
    * Integer 변환 오류 발생, 0 또는 음수 입력 시 `IllegalArgumentException`을 발생시킨다.

---

### 3. 출력 (View)
* "실행 결과" 헤더를 출력한다.
* **각 라운드(차수)별** 실행 결과를 출력한다. (예: `pobi : --`)
* 최종 우승자를 형식에 맞게 출력한다.
    * **단독 우승**: `최종 우승자 : pobi`
    * **공동 우승**: `최종 우승자 : pobi, crong` (쉼표로 구분)
* 예외 발생 시 **`[ERROR]`** 메시지를 출력하고 애플리케이션을 종료한다.



### 4. 유틸리티 (Util)
* 입력받은 자동차 이름 문자열을 쉼표(`,`) 기준으로 분리한다.
* 이름 유효성을 검증한다.
    * 이름이 공백만으로 이루어진 경우는 허용하지 않는다.
    * 다른 문자와 함께 있는 공백은 이름의 일부로 허용하고, 글자 하나로 계산한다.

## 📝 커밋 메시지 컨벤션

프로젝트의 커밋 메시지는 다음 형식을 따릅니다.

```
<type>(<scope>): <subject>
```

### Type

| Type | Description |
| :--- | :--- |
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `docs` | 문서 수정 (README.md 등) |
| `style` | 코드 포맷팅, 세미콜론 누락, 공백 등 (기능 변경 없음) |
| `refactor` | 코드 리팩토링 (기능 변경 없음) |
| `test` | 테스트 코드 추가 또는 수정 |
| `chore` | 빌드, 패키지 매니저 설정 등 유지보수 작업 |
